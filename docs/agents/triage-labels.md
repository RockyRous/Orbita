# Triage labels

The skills use five canonical triage roles. This table maps each role to the GitHub label used by Orbita.

| Skill role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The work is sufficiently specified for an agent. |
| `ready-for-human` | `ready-for-human` | The work needs a human decision or implementation. |
| `wontfix` | `wontfix` | The work will not be actioned. |

Use these strings when applying the corresponding role.
