# Domain docs

This is a single-context repository.

Before working in an established area, read the relevant material in:

- `GLOSSARY.md` at the repository root, if it exists;
- `docs/adr/`, for architecture decisions relevant to the change.

If these paths do not exist yet, continue without raising their absence. Create glossary entries or ADRs only when a term or decision has actually been resolved.

Use vocabulary defined in `GLOSSARY.md` consistently. If a proposed change conflicts with an ADR, identify the conflict explicitly instead of silently overriding it.
