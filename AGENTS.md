## Agent skills

### Issue tracker

Track work in this repository's GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical GitHub label mapping for issue triage. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository. Read relevant domain documentation before changing established concepts. See `docs/agents/domain.md`.

### Product truth

Before changing scope, lifecycle, attention, user flows, or roadmap, read `docs/product/`, `docs/ux/`, and `GLOSSARY.md`.

### Protocol truth

Before changing App Server integration, execution projection, recovery, or compatibility claims, read `docs/protocol/compatibility.md`, `docs/protocol/spike-plan.md`, and relevant ADRs in `docs/adr/`.

### Security and local data

Before changing approvals, rendered agent content, diagnostics, event persistence, redaction, or export, read `docs/security/`.
