# Contributing to Orbita

## Before you start

Search existing GitHub Issues before opening a new one. For a feature, architectural change, or substantial UX proposal, open an issue first so the approach can be agreed before implementation begins.

## Issues

Provide a concise problem statement, expected behaviour, and enough context to reproduce a defect or evaluate a proposal. Do not include credentials, tokens, private logs, or other sensitive data.

## Pull requests

Keep pull requests focused. Explain what changed, why it changed, how it was tested, and link the relevant issue. Update documentation when user-facing behaviour, an architectural decision, or a contributor workflow changes.

## Development status

Orbita is currently at the planning stage. The development toolchain and test commands will be documented when the application skeleton is introduced.

## Conduct

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
