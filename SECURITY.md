# Security policy

## Supported versions

Security fixes are provided for the current development version of Orbita.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository when it is available. If it is unavailable, contact the repository owner through their GitHub profile with the report title prefixed `SECURITY:`.

Include a description of the issue, its impact, steps to reproduce it, and any suggested mitigation. Please allow reasonable time for acknowledgement and remediation before disclosure.
